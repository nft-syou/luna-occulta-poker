# public/kitan — 月蝕綺譚の公式素材

このディレクトリの画像と動画は『月蝕綺譚 -Luna Occulta-』の公式二次創作資料
(<https://vibe.co.jp/luna-occulta/fanworks>) と素材蔵 (kura.vibe.co.jp) から取り込んだものです。
二次創作の掟の範囲で、このゲームが表示するためだけに同梱しています。

- 権利は原作 (CryptoNinja / 月蝕綺譚) にあります。このリポジトリのライセンス (MIT) の対象ではありません。
- 素材集としての転載・再配布、公式と誤認させる使い方は掟で禁じられています。
- 出典と加工内容は `scripts/kitan-assets.json` にあり、`pnpm assets:kitan` で再現できます。
- `voice/` 以下の音声は、公式の声見本 (caption と seed) を Irodori-TTS に読み込ませてこのゲーム用に
  生成したものです。音声そのものの単体再配布・販売はしないでください。

The images and videos here are official 月蝕綺譚 -Luna Occulta- fan-work materials, bundled only so
